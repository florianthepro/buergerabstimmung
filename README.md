# Bürgerabstimmung

Jeder soll seine Meinung vollständig einbringen können: ein Thema selbst
formulieren, begründen und zur Abstimmung stellen. Gewertet wird davon genau
eine Stimme je Thema und Ausweis. Die Begründung darf so lang sein, wie sie
sein muss — das Gewicht ist für alle gleich.

## Funktionsweise

**Anmeldung.** Der Personalausweis weist die Person aus. Gespeichert wird
daraus nur ein öffentlicher Schlüssel: kein Name, kein Geburtsdatum, keine
Adresse.

**Thema.** Titel, Ziel, Begründung, Kategorie und Geltungsbereich
(Deutschland, Bundesland oder Landkreis). Das Ende ist ein Datum, eine
Zielzahl an Stimmen oder beides. Ein Thema pro Person und Tag.

**Abstimmen.** Dafür oder Dagegen, eine Stimme je Thema. 24 Stunden lang
änderbar, danach fest. Die Stimme liegt unter einer aus dem Ausweisschlüssel
abgeleiteten Kennung, die nicht zum Konto zurückführt.

**Melden.** Wer ein Thema für rechtswidrig hält, meldet es unter Angabe der
Rechtsgrundlage. Darüber entscheidet eine unter den Teilnehmern ausgeloste
Jury innerhalb von 24 Stunden.

**Ende.** Mit Ablauf der Frist oder Erreichen der Zielzahl schließt das
Thema. Das Ergebnis bleibt stehen. Gelöscht wird nichts; vor der ersten
Stimme kann die einbringende Person ihr Thema archivieren.

## Stand

Testbetrieb, keine offizielle Seite einer Behörde. Die Anmeldung über die
AusweisApp ist vorbereitet, aber nicht abgeschlossen — bis dahin meldet ein
simulierter Ausweis an.
